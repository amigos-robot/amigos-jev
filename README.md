## ✨ 这是什么？

**AmigosJev** 是 amigos 构建的 Jev 风格**原生多模态决策模型**（激活权重 ~20B）。它把多模态大模型的**下一个词概率分布**直接用作决策输出——不生成文字，答案永远落在你给定的选项范围内。

### 🤖 能控制机器人的决策模型

- 🎥 **摄像头进，动作出**：机器人的第一视角画面 + 状态描述作为输入，选项就是动作指令（前进 / 左转 / 抓取 / 停止……），模型直接告诉你下一步该执行哪个动作
- ⚡ **实时闭环**：100–500ms 的决策延迟，跟得上机器人控制回路的节奏，不用等大模型"慢慢想"
- 🛡️ **输出安全可控**：动作空间由你定义，模型只能在给定选项里选，**绝不会输出计划外的指令**——这对真实硬件至关重要
- 📊 **带置信度的动作**：每个动作都有概率，置信度低时你可以让机器人停下或交由人工裁决

无论是机械臂、轮式小车，还是仿真环境里的 Agent，只要"看画面 → 选动作"能描述成选择题，它就能驱动。

### 👁️ 真正的多模态决策

- 📷 **看图决策**：输入可附带最多 **4 张图片**，模型直接"看"着画面做判断
- 📝 **图文混合**：文本 / JSON 状态描述 + 图片自由组合
- 🧠 **原生多模态架构**：不是"先转文字再判断"，视觉信息直接参与决策推理

### ⚡ 又快又准

- **100–500ms** 毫秒级返回，每个问题只做一次前向推理
- 🎯 **零幻觉**：选项之外的内容被完全屏蔽，概率在给定选项集内重归一化
- 📊 **可解释**：每个选项都带概率与置信度，模型"不确定"时由你裁决

典型场景：**机器人视觉控制**、具身智能、实时游戏操作、Agent 决策、内容审核、图像分类……一切需要瞬间拍板的海量小决策。
